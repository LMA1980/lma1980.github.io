Control-plane token-ID prefix radix index & block lookup (US-06.2.2, ADR-004, features/kv-cache.md).

Provides a concurrent, non-blocking-read prefix radix index keyed by (project_id, model_id, token_ids) aligned to 16-token KV cache blocks (BLOCK_SIZE_TOKENS = 16). Supports longest-prefix match queries, block insertion, LRU eviction, and per-project/per-model invalidation without blocking on compute workers.
