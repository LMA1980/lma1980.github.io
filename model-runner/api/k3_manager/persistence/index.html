Source
Expand description

DuckDB operational metadata store & bounded session persistence (US-17, Features 32, 33, 34, ADR-001, ADR-003).

Implements relational persistence across daemon restarts for tenants, projects, token budgets, tuning profiles, and cumulative usage counters using DuckDB. Provides strictly bounded O(1) single-row last-turn retention per session via SQL upsert (ON CONFLICT (session_id) DO UPDATE SET) and diagnostic replay support.
