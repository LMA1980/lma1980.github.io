k3_manager

Module runtime 

Source
Expand description

Reserved active control thread pool and non-blocking administrative/queue status plane (US-06.2.3, ADR-007, ADR-041).

Decouples control-plane operations (chat template formatting, prompt tokenization, prefix radix lookup, stop-sequence detection, queue depth, active model placements, worker health snapshots, prefix cache stats, and administrative commands) from compute workers so control operations complete immediately on dedicated active control threads (active_control_mask, default 2 threads on X100 cores 6–7) even when compute workers are 100% saturated executing forward passes.
