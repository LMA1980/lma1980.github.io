Struct MultiModelScheduler

pub struct MultiModelScheduler { /* private fields */ }
Expand description

Multi-model compute scheduler arbitrating overlapping reservations at forward-pass boundaries.

Implements:

  • Operator Tuning Immutability (US-08)
  • Multi-Model Coexistence & Overlapping Time-Slicing (US-09)
  • Priority Preemption & Cost-Weighted Fair Sharing (US-10)
  • Opt-In Dynamic Idle Core Spillover & Reclaim (US-11)

pub fn admit_or_register_model( &self, model_id: &str, cluster: String, reservation_mask: u64, tuning: Option<&TuningProfile>, ) -> Result<(), ManagerError>

Admits or registers an active model placement into the scheduler.

If model_id is already registered, updates its placement and tuning configuration. If model_id is new and active models count has reached max_active_models, rejects upfront with ManagerError::ConcurrencyLimitExceeded per ADR-043 and US-09 Scenario 3.

§Errors

Returns ManagerError::ConcurrencyLimitExceeded if capacity is full, ManagerError::Affinity on core mask violation, or ManagerError::WorkerSpawn if unprofiled models attempt to enable lending/borrowing.
