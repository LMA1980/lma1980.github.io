pub fn reconnect_client( &self, session_id: &str, last_acked_token_idx: usize, ) -> Result<Vec<u32>, SessionError>

Reconnects a client within the retention window, returning the catchup tokens generated since last_acked_token_idx and clearing the disconnect state.

§Errors
  • Returns SessionError::SessionNotFound if the session was pruned or never existed.
  • Returns SessionError::RetentionWindowExpired if the elapsed disconnect time exceeds the retention window.
  • Returns SessionError::LockError if lock acquisition fails.
