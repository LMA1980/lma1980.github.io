Module session

Production session retention, catchup stream buffering, and reconnection registry (US-16, ADR-026, features/kv-cache.md).

Provides SessionState and thread-safe SessionRegistry for managing client generation streams, tracking 30-second disconnect retention windows, buffering token generation history for client catchup, and distributing live stream tokens to multi-client subscribers via broadcast channels.
