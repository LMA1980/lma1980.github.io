Cgroup v2 leaf domain placement and OS thread/process affinity fallback.

Enforces control-plane (.../control) and compute worker (.../engines/<model>) isolation domains via cgroup v2 cpuset.cpus with automatic fallback to OS thread/process affinity (sched_setaffinity) per ADR-007, ADR-008, ADR-041, specs/runtime/isolation.md, and Issue #70.
