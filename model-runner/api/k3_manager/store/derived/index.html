Derived Weight Layout Caching & Stale Recipe Detection (US-21, ADR-037, ADR-038).

Caches hardware-repacked (Cluster 1 A100 8x16 i8 IME tiles) or format-converted weights as derived blobs keyed by (source_digest, recipe_version, target_layout). Enforces operator-controlled retention policies, memory admission accounting, and auto-rebuilding of stale derivations upon runtime upgrades.
