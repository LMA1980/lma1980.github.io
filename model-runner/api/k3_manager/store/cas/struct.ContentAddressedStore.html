pub fn promote_staged_blob( &self, staging_path: &Path, expected_digest: &str, format: &str, ) -> Result<PathBuf, K3Error>

Verifies the cryptographic digest and format header of a staged file, then atomically promotes it into blobs/sha256/<digest> (US-18, US-19, ADR-040, Feature 26).

If an identical blob already exists, the staging file is unlinked and the existing blob is deduplicated without duplicating bytes on storage (US-18 Scenario 1).

§Errors

Returns K3Error::CapabilityMismatch if digest verification or format checking fails.

pub fn resolve_alias(&self, alias_str: &str) -> Result<ResolvedAlias, K3Error>

Resolves a human-browsable alias into its manifest and canonical weights path (US-18 Scenario 3).

Verifies symlinks resolve strictly within the store root to prevent path traversal attacks.

§Errors
