Content-Addressed Store (CAS) & Human-Browsable Model Registry (US-18, ADR-035, ADR-036).

Organizes model weights by cryptographic SHA-256 digest (blobs/sha256/<digest>), structured canonical manifests (manifests/sha256/<manifest_digest>.json), and a human-browsable relative symlink alias tree (models/<source>/<namespace>/<name>/<tag>).
