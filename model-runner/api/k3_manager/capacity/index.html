Source
Expand description

Control-plane capacity management, core affinity resolution, and task scheduling.

Re-exports foundational capacity types and cluster masks from k3-core::affinity, and defines the manager-level ControlPlaneScheduler for round-robin control task dispatch, health supervisor watchdog core binding, and compute worker placement validation per ADR-007, ADR-008, ADR-041, and Issue #69.
