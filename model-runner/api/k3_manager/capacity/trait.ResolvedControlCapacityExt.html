fn validate_worker_placement( &self, placement: &WorkerPlacement, ) -> Result<(), ManagerError>

Validates a worker placement compute affinity mask against the resolved capacity.

§Errors

Returns ManagerError::WorkerSpawn if the affinity mask string cannot be parsed, or ManagerError::Affinity if the placement encroaches on dedicated active control cores or exceeds the X100 compute cap.
