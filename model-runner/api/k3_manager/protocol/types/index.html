Protocol front-end common request and response types (US-23, US-24, ADR-015, ADR-020).

Provides canonical representations for OpenAI chat completions, Anthropic Claude messages, Server-Sent Events (SSE), tool calling pass-through payloads, and internal HTTP frames.
