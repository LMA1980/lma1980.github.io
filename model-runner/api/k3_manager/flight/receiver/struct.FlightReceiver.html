pub fn receive_to_memfd(flight_stream: FlightStream) -> Result<RawFd, K3Error>

Implements the PROJECT.md interface contract: FlightReceiver::receive_to_memfd(flight_stream: FlightStream) -> Result<RawFd, K3Error>

Receives all tensor batches, writes them directly into a sealed memfd, calls mlock(), applies F_SEAL_WRITE, and returns the raw file descriptor.
