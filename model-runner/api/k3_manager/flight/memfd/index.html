Module memfd 

Source
Expand description

Anonymous Shared Memory (memfd_create), Sealing, and SCM_RIGHTS IPC (US-19, ADR-037, ADR-041).

Provides an anonymous memory arena for receiving Arrow Flight tensor batches, locking pages in RAM (mlock()), applying write seals (F_SEAL_WRITE), and transferring the sealed file descriptor to compute workers via SCM_RIGHTS.
