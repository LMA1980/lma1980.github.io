Arrow Flight Tensor Batch Streaming (US-19 Scenario 4, ADR-037, ADR-038).

Packages preprocessed and IME-repacked model weight tiles (8×16 i8 blocks per SpacemiT A100 XSMTVDotII matrix core format) into Apache Arrow columnar record batches, streaming them over Flight IPC to remote compute nodes without requiring target-node conversion.
