Module router

Expand description

Decision-model routing for multi-model deployments (US-12, Features 26, 27, 28, ADR-013, ADR-014).

Provides direct named invocation for decision models (e.g. tev1, nimble), content-aware automatic prompt routing for model: auto, structural output constraint matching (json_schema, grammar), and confidence-based fallback escalation chains.
