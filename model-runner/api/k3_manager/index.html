k3-manager: Control plane and IPC daemon for the SpacemiT K3 AI platform.

Supervises isolated k3-worker execution domains (ADR-018, ADR-041), communicates with k3-kv context memory holder (ADR-042), and orchestrates zero-copy forward pass dispatch and crash recovery (US-05).
