Control-plane tokenizer and chat template orchestration (US-06.2.1, ADR-025, ADR-027).

Provides decoupled prompt preparation, chat template formatting, prompt tokenization, context-window admission bounds enforcement, and incremental streaming stop-sequence detection executing exclusively on the control plane without invoking compute workers.
