Isolated Model Ingestion & Source Adapters (US-19, ADR-019, ADR-040, ADR-041).

Exposes external repository lifecycle methods (auth, search, list, pull) with credential isolation, streaming SHA-256 verification, zerocopy header validation, and atomic promotion into content-addressed storage.
