Secret Resolution and Credential Isolation (Feature 30, ADR-041, AGENTS.md §3).

Enforces fail-closed resolution for secrets specified either as literal tokens or file paths (e.g., mode 0600 /etc/k3/credentials/<source>.env). Sensitive credential memory is zeroized via .wipe() using authentic volatile memory writes (std::ptr::write_volatile) upon completion.

Volatiles zeroizes the heap allocation of a String up to its allocated capacity using std::ptr::write_volatile, then clears its length.
