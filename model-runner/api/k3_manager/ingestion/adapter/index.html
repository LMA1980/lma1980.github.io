Source Adapter Contract & Credential Isolation (US-19, ADR-019, ADR-041).

Defines the standard lifecycle contract (auth, search, list, pull) for interacting with external model repositories (Hugging Face, Ollama, private registries) with credential isolation and fail-closed secret resolution.
