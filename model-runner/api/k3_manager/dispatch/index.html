Expand description

Zero-copy forward pass dispatch and Apache Arrow tensor exposure.

Enforces zero bulk tensor payload bytes across Unix Domain Sockets: input tokens are placed in-place into shared-memory slots (wrap_tokens_as_uint32_array), compact ForwardPassCommand descriptors are sent over UDS, and output activations/logits are exposed directly from shared memory as Apache Arrow Float32Array columnar views.
