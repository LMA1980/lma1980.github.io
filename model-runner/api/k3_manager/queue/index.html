Module queue 

Source
Expand description

Patient admission queuing & SSE keep-alive streaming (US-13, Features 29, 30, 31, ADR-015).

Provides per-model FIFO admission queues (default depth 64), wait timeouts disabled by default, zero usage/token quotas, periodic SSE keep-alives (: keep-alive\n\n), advancing queue-position updates (: queue-position <pos>\n\n and : position=<pos>\n\n), client disconnect pruning, and graceful saturation rejection (HTTP 429/529 + Retry-After: <sec>).
