Module gguf 

Source
Expand description

Zero-copy GGUF v3 binary parser, metadata extraction, and tensor descriptor mapping.

Conforms to the GGUF v3 specification and enforces upfront architecture and quantization capability verification (ADR-017, ADR-023, ADR-027, ADR-037).
