Struct ExecutionContext 

Source 
pub struct ExecutionContext<'a> { /* private fields */ }
Expand description

Single-prompt execution context enforcing strict cycle exclusivity (no cross-prompt batching per ADR-005) and fixed n_ctx context window bounds (per ADR-027).
