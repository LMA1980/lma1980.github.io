Struct SharedMemoryArena

pub struct SharedMemoryArena { /* private fields */ }
Expand description

Portable shared memory arena abstraction.

Backed by Linux memfd_create or macOS shm_open / unlinked temporary file. Mapped with MAP_SHARED and provides safe bounds-checked byte slicing.

pub fn evict_lru_intra_arena( &mut self, target_free_blocks: usize, ) -> Result<usize, K3Error>

Scans context blocks strictly within this shared memory arena, identifies unreferenced volatile blocks (meta.is_evictable()), resets up to target_free_blocks of them to TAG_FREE (with committed_token_count = 0), and returns the count of reclaimed blocks.

Eviction is strictly isolated to this arena, never touching or leaking into other model arenas.

§Errors

Returns K3Error if arena header or metadata offsets are invalid.
