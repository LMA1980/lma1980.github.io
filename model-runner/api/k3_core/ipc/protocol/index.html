k3_core::ipc

Module protocol 

Source
Expand description

IPC message schemas, Apache Fory serialization codec, and 12-byte UDS framing.

Provides binary control plane message serialization over Unix Domain Sockets (UDS) for memory management (k3-kv <-> k3-manager) and forward pass execution (k3-manager <-> k3-worker).
