Module layout 

Source
Expand description

In-place shared memory arena layouts for the SpacemiT K3 runtime.

All structures are #[repr(C)] with zero implicit compiler padding, implementing zerocopy 0.8 traits (FromBytes, IntoBytes, KnownLayout, Immutable).

Cacheline-aligned boundaries (64 bytes) ensure optimal memory bus transactions and vector memory operations on SpacemiT K3 X100 (VLEN=256) and A100 (VLEN=1024) cores.
