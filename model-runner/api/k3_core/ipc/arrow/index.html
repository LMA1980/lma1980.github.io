Apache Arrow zero-copy tensor views over shared memory arenas.

Provides zero-copy wrapping of mapped shared memory into Apache Arrow buffers and primitive arrays (UInt32Array, Float32Array).

Zero bulk payload bytes are copied across processes: Buffer::from_custom_allocation retains shared ownership of the backing arena via Arc<dyn Allocation>, allowing readers to inspect tokens, logits, and KV cache blocks via standard Apache Arrow columnar interfaces.
