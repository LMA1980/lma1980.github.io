SpacemiT K3 Cluster 0 (X100) control-plane capacity model, core resolution, and compute bounding.

Enforces dedicated control-plane reservation, spare recovery core allocation, compute capping, and thread-safe round-robin task distribution per ADR-007, ADR-008, ADR-041, and features/core-affinity.md.
