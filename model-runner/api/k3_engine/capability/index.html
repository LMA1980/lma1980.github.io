Architecture recipe capability filter and compile-time registry.

Enforces upfront capability verification against compiled arch-* recipes and compute kernels before reserving or locking memory (ADR-017, ADR-023, ADR-024, US-01 Scenario 1).

RecipeRegistry
In-process compile-time registry mapping GGUF general.architecture strings to compiled ArchRecipe implementations (ADR-023, ADR-024).

verify_model_capabilities
Verifies that the model’s architecture recipe is compiled and that every tensor’s quantization layout is supported by the active backend (ADR-023, US-01 Scenario 1).
