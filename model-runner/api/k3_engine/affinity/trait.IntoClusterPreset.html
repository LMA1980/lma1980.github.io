fn into_cluster_preset(self) -> Option<ClusterPreset>

Converts this compute pool into an optional cluster preset.

Returns Some(ClusterPreset::X100) for ComputePool::X100, Some(ClusterPreset::A100) for ComputePool::A100, and None for ComputePool::Both.
