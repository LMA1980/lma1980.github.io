Struct WorkerPool 

Source 
pub struct WorkerPool { /* private fields */ }
Expand description

Affinity-pinned multi-core compute worker pool (US-01.5.2, US-02 R1, US-03 R1).

Supports three multi-core coordination profiles (spin, futex, rayon), dual-cluster composite backends, pins workers 1-to-1 to physical cores, and instruments cumulative barrier wait times.

Re-reads /proc/self/task/<tid>/status (Cpus_allowed_list) for every active worker thread to confirm strict 1-to-1 core binding and zero cross-cluster migration (US-01.5.2, US-03 R3).
