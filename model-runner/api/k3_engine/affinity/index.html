k3_engine

Module affinity 

Source
Expand description

SpacemiT K3 heterogeneous cluster topology, core mask resolution, and pinned worker pool.

Restricts standalone model evaluation strictly to the operator-requested processor cluster (x100 or a100), core bitmask, and worker concurrency bound while preventing cross-cluster VLEN migration (ADR-007, ADR-008, core-affinity.md, US-01 Scenario 2).
