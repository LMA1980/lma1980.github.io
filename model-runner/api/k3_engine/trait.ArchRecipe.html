Expand description

Architecture recipe trait compiled in-process per ADR-023 and ADR-024.

Each recipe maps a specific general.architecture identifier (treating minor versions such as qwen3 vs. qwen3.8 as distinct algorithms) to single-prompt prefill and decode steps.

Required Methods§

fn architecture_id(&self) -> &'static str

Returns the exact GGUF general.architecture identifier handled by this recipe.

Source

fn supports_quant(&self, quant: QuantType) -> bool

Returns true if this recipe and its linked kernel backend support quant.

Source

fn prefill_step( &self, ctx: &mut ExecutionContext<'_>, weights: &dyn ModelWeights, ) -> Result<(), K3Error>

Executes the prompt prefill forward pass over ExecutionContext::prompt_tokens for a single prompt (ADR-005), populating the KV cache and writing next-token logits.

§Errors

Returns K3Error if a required tensor is missing, has an unsupported quantization layout, or exceeds context window limits.

Source

fn decode_step( &self, ctx: &mut ExecutionContext<'_>, weights: &dyn ModelWeights, ) -> Result<(), K3Error>

Executes a single-token autoregressive decode step using ExecutionContext::decode_token, updating the KV cache at ExecutionContext::position and writing next-token logits.

§Errors

Returns K3Error if no decode token is staged, context bounds are exceeded, or weight lookup fails.
