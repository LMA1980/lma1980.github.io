k3-engine: Low-level compute runtime for the SpacemiT K3 AI platform.

Architecture recipes (arch-*) and compute kernels (kernels-*) are compiled in-process via Cargo feature gates per ADR-024, targeting riscv64gc-unknown-linux-gnu with RVV 1.0 (+v) per ADR-029.
