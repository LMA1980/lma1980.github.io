Module memory 

Source
Expand description

Pre-flight memory footprint calculation and physical RAM admission checks.

Enforces deterministic upfront admission checking against available physical memory (MemAvailable in /proc/meminfo) and process lockable limits (RLIMIT_MEMLOCK), refusing runs before forward passes begin (ADR-027, ADR-037, US-01 Scenario 3).
