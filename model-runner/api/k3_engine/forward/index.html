Heterogeneous-cluster matrix forward workload (US-03, ADR-009, ADR-033, ADR-034).

A deterministic all-integer transformer-style forward pass (RMSNorm, Q/K/V/O and FFN projections, causal attention, LM head) whose matrix multiplications run on either the SpacemiT IME path (smt.vmadot) or the baseline RVV path, and whose operations are placed on the X100 and A100 worker pools according to a PlacementPlan:

  • single cluster: everything on one pool,
  • phase split: prefill and decode on different clusters,
  • operation split: matrix multiplications on one cluster, normalization/attention on the other,
  • row split: every matrix multiplication partitioned across both clusters by output-tile rows in proportion to measured per-cluster throughput (row_split_share).

Accumulation is exact i32 and requantization is integer-only, so the generated token sequence is bit-identical across every placement, split and kernel choice.
