k3-worker: Isolated compute worker library and runtime for the SpacemiT K3 platform.

Provides CLI parsing, memory-locked read-only weight mapping, cluster affinity pinning with conditional /proc/set_ai_thread registration, and zero-copy forward pass dispatch over Unix Domain Sockets using Apache Fory and Apache Arrow zero-copy views.
