pub fn f16_to_f32_finite(bits: u16) -> f32
Expand description

Converts an IEEE 754 half-precision f16 bit pattern (u16) to single-precision f32. Non-finite (NaN/Inf) half-precision bit patterns are mapped to a deterministic finite scale so arbitrary synthetic weight buffers never poison activations with NaN.
