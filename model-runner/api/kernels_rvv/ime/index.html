Module ime

SpacemiT IME (XSMTVDot, smt.vmadot) int8 matrix kernel plus the baseline RVV 1.0 and scalar int8 references it is compared against (US-03 Scenario 2, ADR-034).

All three paths accumulate i8 x i8 products into exact i32 sums, so they are numerically bit-identical; only their throughput differs. That makes the IME on/off delta attributable to the instruction path alone.

§vmadot semantics (measured on the K3 A100 cluster, VLEN = 1024, XSMTVDotII)

On the A100 cluster (VLEN = 1024, vlenb = 128, +xsmtvdotii), smt.vmadot v0, v8, v16 treats v8 as a row-major 8 x 16 i8 tile A (128 bytes), v16 as a row-major 8 x 16 i8 tile B (128 bytes, each row is one output column, k-contiguous) and accumulates the 8 x 8 i32 product C[i][j] += sum_k A[i][k] * B[j][k] into v0:v1 (64 i32 elements, row-major).
