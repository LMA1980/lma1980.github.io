arch-synthetic: Synthetic architecture recipe and deterministic token sampler.

Implements ArchRecipe for the reference synthetic model architecture, reading mlocked weight tensors, updating and reading the 16-token paged KV cache, dispatching kernels-rvv primitives, and performing greedy argmax sampling with lowest-token-ID tie-breaking per ADR-005, ADR-023, and ADR-024.
