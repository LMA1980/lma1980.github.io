Core context memory holder state and shared memory arena management.

Provides thread-safe arena allocation, mapping registry, deallocation, and strict operator LimitMEMLOCK ceiling enforcement (28 GiB reference board ceiling, ADR-037 / AGENTS.md Rule 5).
