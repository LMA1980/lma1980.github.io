Struct KvHolder

pub struct KvHolder { /* private fields */ }
Expand description

Core context memory holder state managing active shared memory arenas.

Designed per ADR-042 (policy-free memory holder) and ADR-037 / AGENTS.md Rule 5 (bounded LimitMEMLOCK ceiling enforcement).

pub fn allocate( &self, config: &ArenaAllocationConfig, ) -> Result<ArenaAllocationResult, KvError>

Allocates and initializes a new per-model shared memory arena.

Sizing is computed from n_ctx, active_slots, head_dim, and num_layers. Sizing is strictly accounted against the operator LimitMEMLOCK ceiling.

§Errors
  • Returns KvError::InsufficientLockableMemory (exit code 11) if the requested capacity would exceed the operator LimitMEMLOCK ceiling.
  • Returns KvError::InvalidDimensions if configuration geometry is invalid.
  • Returns KvError::IpcError if OS shared memory allocation or mapping fails.
