pub async fn enqueue_job(&self, job: Job, log_file: PathBuf) -> EnqueueResult

Enqueues a job into the coalescing FIFO queue.

Rules:

  • Same commit ID conflict resolution & deduplication:
    • merge vs push on the same commit ID: the first event received wins.
    • pull_request vs push on the same commit ID: pull_request always wins.
    • Duplicate events of the same type on the same commit ID: first event received wins.
  • If any older job for the same (repo_name, ref_name, event_type) is currently Queued waiting for execution, it is marked as Skipped (superseded by this newer commit) so limited host resources only build the latest commit on that ref.

pub async fn resume_job(&self, job_id: &str) -> Result<JobRecord, String>

Resumes a job by leaving completed stages intact and returning failed/in-flight stages to Pending. To ensure strict FIFO fairness without line-cutting, the resumed job is moved to the tail of the queue (push_front in the storage deque) with an updated queued_at timestamp. Fails with an error if the job is currently actively Running.
