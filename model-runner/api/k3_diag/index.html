k3-diag: Operator diagnostic CLI binary.

Provides a standalone zero-orchestration tool for verifying model correctness, capability filtering, pre-flight memory admission, locked weight residency (mlock + flock), core affinity, multi-core coordination profiles (spin, futex, rayon), multi-run jitter benchmarking, in-process tokenization, and real-time unbuffered token streaming on SpacemiT K3 hardware (US-01, US-02, US-03 cluster splitting and IME benchmarking, ADR-005, ADR-006, ADR-007, ADR-010, ADR-023, ADR-025, ADR-027, ADR-037, ADR-040).
