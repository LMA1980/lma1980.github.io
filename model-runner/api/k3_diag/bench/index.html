US-03 matrix-forward benchmark: cross-cluster workload splitting and IME isolation.

Runs the engine’s own integer transformer workload (k3_engine::forward) under a chosen placement (--cluster x100|a100, or --cluster both --split phase|op|row) and matrix kernel (--ime on|off), reporting prefill and decode separately against measured hardware ceilings (ADR-034). No external baseline is used (ADR-033) and no pass/fail speed threshold is applied.
